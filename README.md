# Tabs

A personal finance tracker: record what comes in and goes out, organized
around your own financial cycle instead of the calendar month.

Tabs is the successor to Caudal, rebuilt from what that project's growth
taught: keep every feature simple and extensible, not complete on its
first implementation. See the project constitution in
`openspec/config.yaml` for the rules this codebase follows and why.

Status: first feature implemented (`record-and-read-a-cycle`) — record
money in and out, list the active cycle's movements, and read its
balance. Run `make dev` and open the web app.
